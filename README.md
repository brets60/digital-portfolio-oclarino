## 🌟 Featured Project: Speed Detection & Warning System

An autonomous IoT smart road safety prototype designed to detect approaching vehicle speed, broadcast real-time wireless overspeed warnings, and log visual evidence.

- **Microcontroller & Timing**: Arduino Uno / Nano with sub-millisecond transit delta calculation.
- **Wireless Signaling**: 433MHz RF transmitter to roadside flashers.
- **Visual Capture**: ESP32-CAM module triggered on overspeed events.
- **Desktop Station**: Python CustomTkinter supervisory GUI communicating over Serial.
- **Data Persistence**: Local SQLite database logging timestamped speed records and snapshot links.
